##  Project Overview

This project is an end-to-end **Customer Churn Analysis Dashboard** built using **Microsoft Excel**. It focuses on identifying churn patterns, understanding key drivers behind customer attrition, and presenting insights through a clean, interactive dashboard.

The project was completed as part of a scholarship program and represents a practical application of data analysis and dashboard design principles.

---

##  Objectives

* Analyze customer churn behavior
* Identify high-risk customer segments
* Explore churn trends across demographics, geography, and usage
* Transform raw data into actionable business insights

---

##  Dashboard Insights

The dashboard provides insights into:

* Overall churn rate and total customers
* Churn by age groups and demographics
* Top 25 states with the highest churn
* Relationship between customer consumption and churn
* Key churn drivers and patterns

---

##  Tools & Technologies

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers
* Dynamic Excel formulas
* Dashboard design & data storytelling

---

##  Dataset Description

The dataset includes customer-level information such as:

* Customer status and churn indicators
* Demographics (age, gender)
* Contract and payment details
* Subscription types and usage metrics
* Monthly and total charges
